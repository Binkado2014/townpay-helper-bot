# TownPay Helper Bot

TownPay Helper Bot is a simple Towns bot designed to help communities move money with clarity, trust, and ease inside a Town.

## Overview
This bot guides users through sending, requesting, and confirming payments within a Town. It focuses on user experience, transparency, and reducing confusion around community payments.

Theme: Bots that move money

## Who is this for?
- Web3 communities
- DAOs
- Creators
- Town-based groups managing shared funds, tips, or contributions

## Key Features
- Guided payment prompts inside a Town
- Clear confirmation before sending funds
- Transaction summary messages
- Simple commands for sending and requesting payments
- Community-friendly UX focused on trust

## Example Commands
- /pay → Start a guided payment flow
- /request → Request payment from a member
- /confirm → Confirm a pending transaction
- /help → Show available commands

## Demo Flow
1. User types /pay  
2. Bot asks for recipient and amount  
3. Bot shows confirmation summary  
4. User confirms  
5. Bot sends success message

## Status
This is a working demo and concept bot built for the Towns Season One Bot Competition.
